jQuery AJAX: Asynchronous JSON Requests & UI State Lifecycle

Demonstrates $.ajax() with explicit handling of all fundamental network lifecycle states: Loading (in-flight spinner), Success (DOM injection), Empty (no matches), and Error (network/404 handling).

Viva & Practical Concept Covered:

Unlike modern fetch() which requires two steps (fetch().then(r => r.json())) and doesn't reject on HTTP 4xx/5xx status codes, jQuery's $.ajax() parses JSON automatically based on dataType: 'json' and immediately invokes the error callback whenever an HTTP status is outside the 2xx range.
