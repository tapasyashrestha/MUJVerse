📚 AngularJS Concepts Demonstrated on This Page

ng-app="mujverseApp" — declares the module boundary on the <body> element.

ng-controller="EventsController as vm" — attaches the controller; vm is the controller alias (controllerAs syntax).

ng-model="vm.searchText" — two-way data binding: the input is tied to the controller's searchText property.

ng-repeat="event in vm.filteredEvents()" — repeats DOM elements for each item in the filtered array.

{{ vm.searchText }} — expression interpolation renders controller data into the template.

ng-if / ng-show — conditional rendering based on scope state.
