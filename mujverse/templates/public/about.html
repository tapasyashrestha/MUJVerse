About MUJVERSE

MUJVERSE is the unified digital platform for events, experiences, and ticketing at Manipal University Jaipur (MUJ).

Our Vision

Campus life at MUJ is vibrant, diverse, and relentless. From technical hackathons organized by IEEE and ACM, to cultural festivals like Oneiros, sports tournaments, and student club workshops, hundreds of events happen every semester. MUJVERSE replaces scattered forms and posters with a centralized, accessible portal.

Key Highlights

100% Free Registrations

No payment gateways or fees. All campus events are free for verified students.

QR Code Ticketing

Instant cryptographic tickets scanned at venue entrances for seamless check-in.

Role-Based Security

Enforced permissions for Students, Verified Organizers, and Administrators.

Web Technology Project Stack

This system demonstrates modern web engineering concepts required by the curriculum:

  • Backend: Python 3.14 • Django 5.2 LTS MVT Architecture
  • Database: MySQL 8 Relational Database with Transactional Integrity
  • Frontend: HTML5, CSS3, Bootstrap 5.3, Vanilla JavaScript, Fetch API
  • Security: Session authentication, CSRF validation, server-side authorization checks
